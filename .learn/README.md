# .learn: how I'm learning this codebase

This folder is my course on this codebase, run with the `codebase-tutor` skill
(say "start learning session" or `/codebase-tutor start` to any agent).

| File | What it is |
|---|---|
| [FEATURES.md](FEATURES.md) | Every feature the app has, including ones with no UI. I verified each one. |
| [CURRICULUM.md](CURRICULUM.md) | The features I chose, in teaching order, grouped into modules |
| [TRACKER.md](TRACKER.md) | Where I am and exactly where to resume |
| [CONCEPTS.md](CONCEPTS.md) | Every concept I've learned and the lesson that taught it |
| [playground.md](playground.md) | Today's lesson (open in Markdown Preview: Ctrl+K V) |
| [lessons/](lessons/) | Finished lessons |
| [captures/](captures/) | Real requests, responses and logs captured for lessons |
| [blueprint.md](blueprint.md) | What worked and what didn't in how I study this project |

## Commands

`start` · `pause` · `done` · `note` (to knowledge base) · `quiz` · `explain <tool>` · `refresh` (code changed)

## Notes

Notes don't live here. Each concept I learn goes into my central knowledge base
(`E:\Learning\My_tech_knowledgebase`) as a project-independent note; `CONCEPTS.md`
links to them.
